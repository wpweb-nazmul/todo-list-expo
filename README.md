# Todo List Expo App

A complete React Native + TypeScript Todo List app with:
- Add tasks
- Mark tasks completed / active
- Delete tasks
- Filter All / Active / Completed
- Clear completed tasks
- Save tasks locally using AsyncStorage

## Run

1. Open this folder in VS Code.
2. Open Terminal: **Terminal → New Terminal**
3. Run:

```bash
npm install
npx expo start
```

4. Press `w` for web, or scan the QR code with Expo Go on your phone.

If Expo reports a dependency version mismatch, run:

```bash
npx expo install --fix
```
